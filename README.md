# Anamoly-activity-detection-using-cnn-and-rnn
Anomaly activity detection plays a crucial role in various domains such as video surveillance, healthcare monitoring, and industrial automation, where identifying irregular or unexpected behavior is essential. This work explores a hybrid deep learning approach that combines Convolutional Neural Networks (CNNs) and Recurrent Neural Networks (RNNs) for robust anomaly detection in spatiotemporal data. CNNs are employed to extract high-level spatial features from individual frames or sensor readings, capturing visual or contextual patterns. These features are then fed into RNN architectures, particularly Long Short-Term Memory (LSTM) networks, to model temporal dependencies and detect deviations in sequential behavior. The integrated CNN-RNN model enables the system to learn both appearance and motion cues effectively. Experiments demonstrate that the proposed method achieves high accuracy in distinguishing normal from abnormal activities, even in complex and dynamic environments. The framework supports both supervised and semi-supervised settings and addresses key challenges such as data imbalance and real-time processing.
